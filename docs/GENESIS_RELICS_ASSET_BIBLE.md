# GENESIS RELICS — ASSET BIBLE v1.0

**Status:** Canonical production planning document  
**Rule:** Existing production asset IDs GR-001–GR-030 are immutable and will not be renumbered or repurposed.  
**Scope:** Website, Board Game, Digital Game, Lore, Community and future Kickstarter production.

---

## 1. Asset ID Policy

1. Every asset receives a permanent Genesis Relics ID.
2. An assigned ID is never reused for a different asset.
3. Existing GR-001–GR-030 remain unchanged even where the original early planning document used different names.
4. New production continues from GR-031 onward.
5. GR-100+ is reserved for secondary faction/system assets and other clearly separated asset families.
6. A missing asset may remain **PLANNED** or **NEEDED**; the code must not silently treat a missing production asset as an existing file.
7. File names, registry entries and UI slots should reference the canonical asset ID and canonical name.

### Status legend

- 🟢 **EXISTS** — final/current asset exists in the repository.
- 🟡 **PLANNED** — reserved in the Asset Bible but not yet produced.
- 🔴 **NEEDED** — currently referenced by the application but the production asset does not yet exist.
- ⚪ **UNASSIGNED** — reserved ID with no approved asset definition yet.

# 6. Production Target

The goal is not to create every reserved ID.

The initial target is approximately **80–120 high-quality production assets**, growing only where the website, Board Game, Digital Game, lore, community or Kickstarter campaign requires them.

Priority order:

1. Existing GR-001–GR-030 — preserve and verify.
2. Fix or produce assets currently referenced by the application, especially GR-100–GR-123.
3. Produce GR-031–GR-052 according to actual content needs.
4. Expand World, Relics, Board Game and Digital Game libraries.
5. Add Kickstarter and marketing assets as campaign requirements become concrete.

---

# 7. Asset Production Record

For every new asset, record:

- **ID**
- **Canonical name**
- **Category**
- **Purpose**
- **Status**
- **Dimensions**
- **Format**
- **Aspect ratio**
- **Visual description**
- **Required characters / objects**
- **Faction / region**
- **Where used on the site**
- **Source / generation method**
- **Final approved filename**

No production image should be generated without an assigned Asset ID and approved purpose.

---

## 8. Canonical Rule

**Genesis Relics is building an IP asset library, not a collection of disconnected website images.**

Every image must have a permanent identity, a purpose in the world, and a known place in the wider Genesis Relics production system.
