# GR-031 — Miniatures

- **ID:** GR-031
- **Name:** Miniatures
- **Category:** Board Game
- **Purpose:** Establish the canonical visual presentation of the physical Genesis Relics miniatures and demonstrate the tabletop scale, sculpt quality, faction identity, and production-readiness of the board game.
- **Status:** 🟡 PLANNED — concept approved; final production artwork not yet approved.
- **Dimensions:** 3000×3000 px
- **Format:** PNG
- **Aspect Ratio:** 1:1
- **Description:** A premium tabletop presentation featuring four highly detailed Genesis Relics character miniatures, one representative hero from each faction, standing on elegant game bases on a dark stone game table. Guardians, Voidborn, Architects, and Ashen Covenant must be visually distinct and faithful to the established hero designs. The composition should feel like a real high-end board-game prototype rather than generic fantasy figurines. Include subtle board-game context without making the scene visually crowded.
- **Required Characters / Objects:** Four faction-representative hero miniatures; miniature bases; subtle tabletop surface; restrained Genesis Relics board-game atmosphere.
- **Faction / Region:** Guardians, Voidborn, Architects, Ashen Covenant.
- **Where Used:** Board Game page; Kickstarter campaign; product presentation; future rulebook/component documentation.
- **Visual Direction:** Dark fantasy, premium tabletop photography, black/obsidian surfaces, restrained antique-gold accents, cinematic but physically plausible lighting, highly detailed sculpted materials, consistent Genesis Relics visual language.
- **Quality Requirement:** No invented faction symbols, no random weapons that contradict established heroes, no text embedded in the artwork, no duplicated characters, no malformed anatomy or miniature bases.
- **Production Rule:** GR-031 remains permanently assigned to Miniatures. If the artwork is replaced later, the Asset ID and canonical purpose remain unchanged.
